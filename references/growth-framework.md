# 增长空间与增长质量分析框架（Phase 3 第 3 维）

增长分析的两半：**空间**（能长多大）和**质量**（长大是否创造价值）。只做第一半会掉进增长陷阱——Siegel 的研究证明高增长行业长期回报常低于低增长行业，因为增长被高估值和股本稀释吃掉。

## 第一半：增长空间

### 1. TAM 三算法交叉

- 自上而下：行业总规模 × 可服务比例（引用研报/统计局/行业协会数据，注明来源）
- 自下而上：潜在客户数 × 渗透率 × ARPU（更可信，优先）
- 类比法：对标成熟市场同类公司的人均消费/渗透率天花板
- 三种算法差异大时如实呈现区间，不取悦性地选大数。

### 2. S 曲线定位

判断行业处于导入期/成长期/成熟期/衰退期。证据：渗透率绝对值与增速二阶导、行业价格战烈度、行业资本开支趋势、头部集中度变化。
- 渗透率 < 10%：故事期，高不确定性
- 10%~40%：黄金成长期
- \> 50% 且增速放缓：存量博弈，增长只能来自份额与提价
- 衰退期：按烟蒂/现金奶牛逻辑分析，不谈成长

### 3. 增长来源分解

未来 5 年收入增长 = 行业增长 + 份额提升 + 提价 + 新业务 + **并购（外延）**。逐项给出估计与依据。依赖"新业务"占比越高，可信度越低（新业务成功是低概率事件，除非已有验证数据）。

- **份额提升**：必须挂 Phase 3 护城河/成本优势的具体证据（为什么抢得到份额）——无证据的份额假设是叙事，不是估计。
- **并购（外延）**：与有机增长**分开拆**。商誉驱动的收入增长（引擎有 `GOODWILL_ACQUISITION_DRIVEN` 告警，与 Phase 0 商誉排雷联动）必须过两问：并购溢价挣得回来吗（被并业务后续 ROIIC vs 收购价隐含的回报要求）？收入增量里有多少来自并表口径而非真增长？有机与外延混在一起的增速序列喂给估值，等于把并购决策的质量伪装成经营能力。
- **增速假设挂基率检验**：分解出的每个增速假设，进入估值前必须过 [valuation-guide.md](valuation-guide.md) 的基率表（历史同等规模公司的达成比例；落在前 10% 区间的假设必须给出"它是例外"的具体证据）。

## 第二半：增长质量（ROIIC 检验）

巴菲特原则：只有增量投入资本回报率（ROIIC）> 资本成本的增长才创造价值。

**计算**：ROIIC ≈ （NOPAT_t − NOPAT_t-n）/（投入资本_t − 投入资本_t-n），取 3 年和 5 年滚动窗口。

**判读**：
- ROIIC > 15%：增长是价值机器，值得公司保留利润再投资
- ROIIC ≈ WACC：增长不增值，公司应该多分红回购
- ROIIC < WACC：增长毁灭价值——收入涨股价跌的常见原因，警惕"为增长而增长"的帝国建造型管理层

**再投资跑道（reinvestment runway）**：李录/喜马拉雅关注的复利机器核心 = 高 ROIIC × 长跑道。有高回报但没地方再投（跑道短）→ 好生意但成长有限，看股东回报；有跑道但回报低 → 增长陷阱。**判定方法与评级×跑道四象限约束见 [moat-framework.md](moat-framework.md) 步骤 4**（单一判定源，防止两文件漂移），本文件只保留增长视角的结论。

## 增长侧跟踪信号（对接 Phase 5 跟踪清单与证伪条件）

增长假设是估值的最大输入，其证伪信号必须与护城河侵蚀信号（moat-framework 步骤 5）对称地进 Phase 5 季度跟踪清单——按本案增长来源选 2~3 条：

| 增长来源 | 季度级证伪信号 |
|---|---|
| 行业增长（渗透率驱动） | 渗透率增速二阶导转负；行业价格战烈度升级（S 曲线阶段提前切换） |
| 份额提升 | 市占率环比连续两季走平/回落；头部对手反向扩张的产能/价格公告 |
| 提价 | 提价公告后销量与市占率的兑现（提价掉量 = 定价权假设错）；通胀回落期的顺价能力 |
| 新业务 | 里程碑延期或砍线公告；单位经济未按计划收敛 |
| 并购（外延） | 商誉减值预告；被并业务业绩承诺未达标 |

判读纪律与护城河侧一致：**单季波动不算证伪，连续两季同向才进证伪评估**。

## 第三半：成熟态三段式与成长股估值通道（Phase 4 输入，REQ-P1-01）

适用对象：卡二再投入子型（当期 OE 被增长性资本开支压低甚至为负、但单位经济已证的公司）。对这类公司，OE 三情景 DCF 是用错了尺子——它把"为未来投入"和"赚不到钱"混为一谈（Netflix 2016 案：131x OE 下任何买入档位数学不可达，全回测最深假阴性）。通道以**成熟期稳态利润 × 到达概率折回**替代当期 OE 基期，四段输入全部强制挂证据：

### 1. 单位经济（第一道门，不过即通道不适用）

区分"再投入"与"烧钱"的唯一可量化标准，两个判据任一不过 → `GROWTH_UNIT_ECONOMICS_UNPROVEN`，通道拒绝服务（exit 2），改走标准管道：

- **规模化边际贡献率** =（收入 − 直接变动成本：内容/获客/履约）÷ 收入。≤0 即每多做一个单位生意就多亏一份钱，增长本身在毁灭价值。证据形态：分部贡献利润率（Netflix US 2015 为 44%）、单会员月收入 vs 单会员月直接成本（7.32 vs 内容 7.67 的对照即是判据素材）。
- **LTV/CAC** ≥1（可得则必查）：<1 即获客在毁灭价值。LTV 用保守口径（当期边际贡献 × 保守存续期，不用管理层口径的"终身"）。

### 2. 渗透率天花板（成熟态收入的来源）

自下而上：**成熟会员/用户数 × 成熟 ARPU**。天花板锚定可用渗透空间（S 曲线第 2 节），禁止用"当前增速外推 N 年"——那是把增速当天花板。ARPU 只认已实证的定价权（提价后留存数据），无实证则按当期值持平处理。三算法差异大时取区间，成熟态取区间下沿偏上，乐观情景才可用上沿。

### 3. 成熟期利润率反推（成熟态 OE 的来源）

禁止从当期利润率线性外推（投入期利润率无意义），两条反推路径：
- **单元经济法**（首选）：规模化边际贡献率 − 成熟期固定费用率（技术平台/管理费用占收入比的历史带宽下沿）。
- **同业成熟态法**：该商业模式已成熟的公司（或本公司最成熟分部）的实际利润率，需论证可比性。

### 4. 到达概率与基率锚

p_arrival = 增长兑现 ∧ 利润率扩张 ∧ 竞争存活的**联合概率**，机器纪律：
- **不得高于收入基率锚**（同等规模公司达成所需 10 年 CAGR 的历史比例，引擎按 valuation-guide 基率表自动反查；REQ-P1-05 基率表建成后由 `--base-rates-file` 接管）。超出即 `GROWTH_ARRIVAL_PROB_ABOVE_BASERATE`，须在 basis 中论证例外。
- **概率语义**：多情景混算时 p 为条件概率（给定该情景世界），无条件到达概率 = Σ 情景概率 × 条件 p，**整体**须 ≤ 基率锚。
- 失败残值（1−p 分支）建议复用悲观情景的独立方法锚（历史最差年×危机倍数/清算），两处同源。

### 引擎与档位语义

```
python3 scripts/reverse_dcf.py growth --market-cap <市值> --current-revenue <当期收入> \
  --mature-revenue <成熟收入> --mature-oe-margin <成熟OE利润率> \
  --terminal-multiple <终局倍数> --arrival-prob <p> --years-to-maturity <N> \
  --shares <股本> --contribution-margin <边际贡献率> \
  --failure-equity-value <失败残值> \
  --mature-state-basis "<[E:]>" --arrival-prob-basis "<[E:]>" -o data/growth_value.json
```

- **反向求解**：本通道的反向 DCF = 现价隐含到达概率。`implied p ≥100%`（`GROWTH_PRICE_IMPLIES_CERTAIN_ARRIVAL`）即连必然到达都解释不了现价——透支。`implied p ≥ 2×基率锚`（`GROWTH_IMPLIED_VS_BASERATE_GAP`）即市场对到达的定价远超历史达成比例——分歧显式化。
- **终局倍数 vs Gordon**：两口径都会输出；分歧 >30% 报告必须双口径并列（市场倍数含质量溢价，Gordon 是纪律下限），所选口径须论证。
- **档位上限恒为小仓位试探**（`GROWTH_TERMINAL_DOMINATED`：通道价值 100% 来自成熟期终值折回，按终值纪律禁止以安全边际单独支撑核心买入）。引擎档位带建议：单元经济已证 + implied p <100% → 观察等价格；价格 ≤ 概率加权成长价值 → 小仓位试探候选（仍须过 expected-return 闸门二）；implied p ≥100% → 拒绝（透支）。
- **与三情景衔接**：基准/乐观情景 `method` 登记 `growth_terminal_backcast`（check_scenarios 已注册）；悲观情景仍须独立方法。持有期建议取到达年数 N（价值在 N 年兑现，5 年期 IRR 会系统性低估长跑道复利）。
- **通道判别力**：Netflix 型（贡献利润率 44%）与乐视型（内容成本无边界、贡献率为负）在本通道得到相反结论——这正是通道存在的目的；单元经济未证的公司禁入，不得通过调高 p 或倍数让它"看起来值钱"。

## 输出

- TAM 区间 + 当前渗透率 + S 曲线阶段
- 未来 5 年收入增长分解表（行业/份额/价/新业务/并购——有机与外延分开列）
- ROIIC 序列 + 判读：增长创造价值 or 毁灭价值
- 再投资跑道判断：这家公司未来 10 年能把多少利润以高回报再投出去（判定见 moat-framework 步骤 4）
- 增长侧跟踪信号 2~3 条（进 Phase 5 跟踪清单）
- （再投入子型）成熟态三段式四输入：边际贡献率/LTV-CAC、成熟收入、成熟 OE 利润率、到达概率与基率锚——供 Phase 4 成长通道
