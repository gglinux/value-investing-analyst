# 商业模式与护城河分析框架（Phase 3 第 1、2 维）

## 第一节：商业模式分析

段永平："商业模式是投资中最重要的事。"回答四个问题，每个都要有明确答案：

1. **怎么赚钱**：收入公式拆到最细（量 × 价，或 用户 × ARPU，或 资产 × 回报率）。钱最终从谁的口袋出来？付钱的人得到了什么？**量与价必须挂 `data/business_drivers_<公司>.json` 的实际数字**（Phase 2 已落盘并过勾稽），不允许只写定性描述——说不出量和价各是多少、各自怎么变，等于没拆开这门生意。
2. **单位经济**：卖一单/服务一个用户，赚多少钱？规模扩大时单位经济变好（规模经济）还是变差（规模不经济）？
3. **客户为什么不走**：复购/续费的真实原因——是没得选、换不动、还是真心喜欢？三者的护城河强度完全不同。
4. **可持续性**：这个赚钱方式 10 年后还成立吗？最可能被什么杀死（技术替代/监管/消费习惯迁移/供应链变化）？

### 所有者代入拷问（本节强制输出，紧接四问之后）

**买股票就是买公司**——把上面四问的答案放到"如果这家公司整体归我"的场景里再过一遍。这不是修辞，而是能逼出前四问漏掉的东西：

1. **如果用现在的市值把整家公司买下来（100% 私有化），我愿意吗？** 明确写出：买下后每年能拿到多少可分配现金（用 Owner Earnings，不是净利润），相当于几个点的收益率（Owner Earnings / 市值 = 所有者收益率），多少年回本。这个数字比 PE 更接近所有者的真实体验。
2. **买下之后，我第一件想改的事是什么？** 答案指向这门生意最脆弱或最被浪费的环节（过度扩张、渠道压货、薪酬结构、无效并购）。若"什么都不想改"，说明公司已被优秀经营——这是强正面信号，但必须给出理由。
3. **这门生意有什么是我不看财报也能理解的？** 一句话说清价值创造的物理过程（把砂变成算力、把水变成品牌溢价、把流量变成撮合）。说不清 → 回到 Phase 0 能力圈终止路径。
4. **我最不希望竞争对手做的一件事是什么？** 这是护城河的反向定位——真正的威胁往往不在当前的竞争维度上（柯达怕的不该是更好的胶卷）。该答案直接进 Phase 5 红队的最强空头逻辑。

### 增长引擎归因（挂 Phase 2 量价分解）

这门生意过去 5~10 年的增长，究竟来自**量**（更多客户/更多门店/更多产能）、**价**（提价/结构升级）、还是**新业务**？三者的所有者含义完全不同：靠价增长通常不需追加资本（品牌型，最优）；靠量增长需要持续 capex 与营运资本（重资产型，要看 ROIIC）；靠新业务则历史财务几乎无参考价值。结论必须与 Phase 2 量价分解图的数字一致，并在 Phase 4 作为收入增速假设的直接依据——**估值里的"增速 X%"必须能说清是量还是价**。

输出格式：一段"用大白话讲这门生意"（假设讲给完全外行听），加一张商业模式画布式要点表，加上述所有者代入拷问四答与增长引擎归因一句话。讲不清楚 = 超出能力圈，回到 Phase 0 的终止路径。

## 第二节：护城河分析（Morningstar 五源框架 + 定量验证）

### 输出词表纪律（强制——两道闸门的门槛挂在这个词上）

**护城河评级只能输出三个值：宽 / 窄 / 无**（对应 `scenarios.json` 的 `moat` = `wide` / `narrow` / `none`）。禁止自造中间档。

原因不是术语洁癖，而是**两道闸门的门槛直接挂在这个词上**：闸门一的安全边际要求（宽 ≥25% / 窄 ≥40% / 无 → 不给买入结论），以及闸门二由它反推的期望 IRR 门槛（r=10%/H=5 时 16.5% / 21.8%）。评级词一含糊，两个门槛就都无从取值。

归档案例中过半用过自造评级词（"极强""中强"）或根本没写评级。**自造词无法机械映射到门槛，"极强"是宽还是超宽？"中强"是宽还是窄？——这直接决定安全边际要 25% 还是 40%，差 15 个百分点。**

判定口径（与 Morningstar 一致）：

| 评级 | 判据 | 安全边际要求 |
|---|---|---|
| **宽**（wide） | ROIC 持续显著高于 WACC，且有充分理由认为**未来 20 年**仍能维持 | ≥25% |
| **窄**（narrow） | 当前有超额回报，但只能确信维持**约 10 年** | ≥40% |
| **无**（none） | 无可验证的持续超额回报，或护城河正在被侵蚀且无止损机制 | 不给买入结论（无论多便宜，除非烟蒂式清算价值明确） |

介于宽窄之间拿不定主意时**一律降档取窄**——这是安全边际原则在评级环节的应用，不是妥协。`check_scenarios.py` 的 S1 会硬拒绝非法档位值。**REQ-P1-03**：给出定量得分（第二节半）时门槛走平滑函数，评级词=得分投影，"拿不定主意"升级为"打分 + 边界带双档披露"。

### 评级输入定标与边界态（已并入第二节半）

资源/成本型定标判据（成本曲线前 20% 分位 / 结构性闭环 / 份额趋势）与边界态双档披露规则已机器化并入第二节半的 C 组件与边界带纪律，此处不再重复维护（防止两处漂移）。

**边界态处理（REQ-P1-03 起机器化）**：得分落分带边界 ±5 分 → 引擎自动输出双档报告（`MOAT_BOUNDARY_BAND_DUAL`，规则见第二节半边界带纪律）。

### 第二节半：护城河定量得分 0~100 与平滑门槛（REQ-P1-03，强制输出）

动因见上：离散词 + 阶跃门槛把"全流程主观性最高的环节"放大成档位跳变（神华案一字之差跳 2 档），是传导机制问题而非分析质量问题。

**三组件评分**（每项挂 [E:]，合计 clamp 到 [0,100]）：

| 组件 | 分值 | 判据 |
|---|---|---|
| **A 超额回报证据**（ROIC−WACC，核心检验） | 0~50 | ≥10 年持续正利差且当期仍宽 → 50；≥10 年正利差但当期收窄近零 → 40；5~10 年 → 30；序列 <5 年 → ≤15 且**评级上限窄**；时正时负/当期负 → 0~15。周期类用**跨周期均值口径**，不拿景气顶当证据、也不拿谷底单独定罪 |
| **B 源硬度**（步骤 1 五源 × 步骤 2 定量验证） | 0~30 | 每个**有硬证据**的源 10 分，最多计 3 源。硬证据：成本优势须有成本曲线分位或进攻者尸检；无形资产须过定价权三测试至少 2 项；网络效应须有份额/多归属数据；转换成本须有 NDR/流失数据；有效规模须有新进入者失败史 |
| **C 定标与趋势修正** | −10~+20 | 资源/成本型定标判据（上节）：成本曲线前 20% 分位 +5、结构性闭环 +5、份额趋势向上 +5；趋势：变宽 +5 / 稳定 0 / 稳定偏变窄 −5 / 变窄 −10 |

**分带与平滑门槛**（评级词 = 得分的分带投影，词表 {wide,narrow,none} 不变；闸门二①门槛由 MoS 反推，r=10%/H=5：50%→26.4%、40%→21.8%、25%→16.5%）：

| 得分 | 评级词 | 闸门一 MoS 门槛（平滑函数） |
|---|---|---|
| ≥65 | wide | 40%（65 分）线性降至 25%（100 分） |
| 35~64 | narrow | 50%（35 分）线性升至 40%（65 分） |
| <35 | none | 不给买入结论（政策边界，非数值边界） |

平滑函数性质（`reverse_dcf.py mos_requirement_from_score`）：**分带边界处连续**（65 分两侧都是 40%）——评级词跨带变动时门槛变化趋零，"一字之差跳两档"从机制上归零；**带内处处 ≥ legacy 阶跃常数**（仅锚点相等：65 分=旧窄锚 40%、100 分=旧宽锚 25%）——通道建设而非阈值放松。得分落边界带（±5 分）→ 双档报告并列两侧结论并标注「结论对护城河判断敏感」，告知投资者本案最该花研究精力的判断就是护城河得分。

**引擎用法**：`expected-return --moat-score <0~100> --moat-score-basis "<A/B/C 各挂 [E:]>" --moat-sources <硬证据源>`（或把三字段登记进 scenarios.json，S1b 校验）。纪律：basis 必填含 [E:]（`MOAT_SCORE_BASIS_MISSING`）；词必须等于得分投影（`MOAT_SCORE_WORD_MISMATCH`）；仅给词走 legacy 常数（存量基线不动），新案例（第四批起）强制带得分。

**验收锚（神华 2015，全记录见 backtest/601088.SH_2015-12-31/data/expected_return_moat_score_REQ-P1-03.json）**：60 分双档报告中 65 分侧触发价恰为归档 legacy 触发价（连续性锚实证）；连续化没有放松任何门槛，它把"措辞决定档位"换成"得分决定门槛 + 边界分歧显式披露"。

### 步骤 1：定性归类（五源）

| 护城河来源 | 判断标志 | 典型案例 |
|-----------|---------|---------|
| 无形资产 | 品牌带来提价权；专利/牌照排他 | 茅台、迪士尼、创新药专利期 |
| 转换成本 | 客户换供应商的代价高（金钱/风险/学习） | 企业软件、银行核心系统、医械耗材 |
| 网络效应 | 用户越多产品越好用，赢家通吃 | 微信、Visa、交易所 |
| 成本优势 | 规模/工艺/资源/区位带来结构性低成本 | 台积电、Costco、低成本矿山 |
| 有效规模 | 市场只容得下少数玩家，新进入者进来大家都亏 | 机场、管道、区域水泥 |

注意：**好产品、大市占率、优秀管理层本身都不是护城河**。护城河必须回答"为什么竞争对手拿着钱也抢不走"。

### 步骤 2：定量验证（硬证据，缺一项降级）

- **ROIC − WACC 利差**：正利差持续 ≥ 10 年 → 宽护城河候选；≥ 5 年 → 窄护城河候选；时正时负 → 无护城河。这是 Morningstar 的核心检验。**序列不足 5 年**（上市短、次新公司）：评级上限为窄，且必须靠定标判据/进攻者尸检/定价权测试补证据，禁止凭叙事升宽——数据不足按保守侧处理。
- **毛利率波动带**：10 年毛利率带宽窄且高于同行 → 定价权证据。
- **市占率趋势**：5~10 年市占率稳定或提升。份额持续流失的"护城河"是伪命题。
- **定价权三项硬测试**（巴菲特："判断一家企业最重要的单一指标是定价权"。三项都要有数据，缺数据标明缺失，不许用"品牌力强"之类形容词代替）：
  1. 提价记录：过去 10 年公司实际提价几次、每次幅度（对比 CPI 与行业均价）；
  2. 销量反应：每次提价后销量/市占率是否受损（提价不掉量 = 真定价权）；
  3. 成本转嫁：原材料/人力成本大涨年份，毛利率是守住了（转嫁给下游）还是被压缩（自己硬扛）。
- **进攻者尸检**：过去 10 年谁试图进攻过这个位置？带着多少钱？结局如何？（有资本进攻失败的历史是最强证据；从没人进攻可能只是市场太小）

### 步骤 3：趋势判断（比"有没有"更重要）

护城河在变宽还是变窄？证据：ROIC 利差的方向、市占率二阶导、单位成本差距变化、技术范式是否迁移（柯达的品牌护城河死于数码，不是死于竞争对手胶卷做得更好）。

### 步骤 4：再投资跑道判定（护城河 × 增长容量的交叉，Phase 3 → Phase 4 的硬交接）

护城河回答"超额回报能否持续"，不回答"超额回报能否滚动复利"——两者组合才是所有者回报的完整形状，也是估值增速假设的合法来源：

| 组合 | 典型 | 所有者回报路径 | 对估值增速假设的约束 |
|---|---|---|---|
| 宽 + 长跑道 | 早期台积电、Costco | 复利机器：高 ROIIC × 高再投资率 | 增速可用「再投资率 × 增量 ROIIC」推导 |
| 宽 + 短/无跑道 | 茅台、成熟期可口可乐 | 现金牛：高分红/回购是资本配置的**正确终局**，不是失败 | 增长只能来自提价（须过定价权三测试）或新业务；`--iv-growth` 取保守提价带 |
| 窄 + 长跑道 | 扩张期连锁（单店模型已验证） | 价值创造但脆弱：跑道赌的是护城河撑到回收 | 增速假设按单店/单位回收期证据打折 |
| 任何评级 + 无跑道 + 无定价权 | — | 价值陷阱高发形态 | 增速假设必须 ≤ 行业中枢，禁止给复利叙事 |

**跑道判据（两项都要过才算长）**：① **增量资本回报**：再投资率 × 增量 ROIIC 显著高于市场中枢（ROIIC 序列 metrics 已有）；② **再投资容量**：TAM/份额空间未耗尽，或单位经济已验证可复制（单店/单客户回收期 < 资产寿命）。任一不满足 → 跑道判"短/无"，禁止按复利机器外推。

**输出**：跑道 长 / 短 / 无 + 一句话判据，写入护城河结论。它是 Phase 4 增速假设与 `--iv-growth` 取值的直接依据（假设一致性对账第 ③ 条的输入）、company-types 缓慢增长卡的判据来源之一。

### 步骤 5：侵蚀预警信号（对接 Phase 5 季度跟踪清单与证伪条件）

趋势判断的证据是年报级的——年报出来时护城河往往已经窄了一年。按主护城河源选 2~3 条**季度级领先信号**写进 Phase 5 跟踪清单，让侵蚀被看见而不是被追认：

| 主护城河源 | 季度级侵蚀信号 |
|---|---|
| 无形资产（品牌） | 提价后销量/市占率拐点；渠道库存环比；合同负债/预收环比连续两季走弱 |
| 转换成本 | NDR/续费率环比下降；头部客户流失公告；使用量（seats/交易数）增速先于收入掉头 |
| 网络效应 | MAU/DAU 二阶导转负；多归属（multi-homing）迹象——双边任一侧头部参与者开始同时经营对手平台 |
| 成本优势 | 单位成本分位漂移（行业成本曲线数据）；原料/汇率冲击年份毛利率跌幅大于同行 |
| 有效规模 | 新产能/新牌照获批公告；区域市场价格战开启 |

判读纪律：**单季波动不算侵蚀，连续两季同向才进证伪评估**——护城河的定义就是抗单次冲击的能力，跟踪清单警戒线必须体现这个时间尺度（写"连续两季"，不写"单季跌破 X"）。

## 第三节：产业链议价权（五力的纵向两力，直接约束利润率假设）

护城河五源回答"同行为什么抢不走"，本节回答"**上下游为什么分不走**"——利润率的持续性同时受这两个方向挤压，估值里的利润率假设必须同时过这两关。三组证据，全部可从现有底稿与年报附注取数，禁止用"关系稳定"之类形容词代替：

1. **集中度对照**（年报附注披露）：前五大客户占收入比 vs 前五大供应商占采购比。一边高度分散、一边高度集中 → 集中的一方是强势方。危险组合：大客户集中（>30%）且客户自己在做垂直整合（如云厂商自研芯片之于英伟达）。
2. **占款能力趋势**（底稿现成数据）：(应付+预收/合同负债 − 应收 − 存货) / 收入 的 10 年趋势。持续为正且走阔 = 两头占款，产业链话语权强（茅台、Costco 模式）；持续为负且走阔 = 被两头占款，赚的是辛苦钱且在恶化。这是议价权最难粉饰的定量指标。
3. **成本冲击传导记录**（与定价权测试第 3 项联动）：上游涨价年份，公司毛利率与下游客户毛利率谁被压缩？连续两轮冲击都是自己扛 → 对下游无议价权，利润率假设必须按"周期均值偏下"取，禁止按近年高点外推。

输出：上游议价权 强/中/弱 + 下游议价权 强/中/弱 + 一句话依据（挂数据）+ 对估值利润率假设的明确约束（如"下游议价权弱 → 基准情景毛利率取 10 年中位数而非近 3 年均值"）。该约束进入 Phase 4 假设一致性对账的核对清单。

### 输出

护城河评级：宽 / 窄 / 无 + **定量得分 0~100（三组件分项分 + 五源支持数，REQ-P1-03 强制；边界带附双档报告）** + 趋势：变宽 / 稳定 / 变窄 + 跑道：长 / 短 / 无（一句话判据）+ 一句话核心依据 + 最大侵蚀风险 + 季度级侵蚀信号 2~3 条（进 Phase 5 跟踪清单）。
