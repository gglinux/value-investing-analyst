# 商业模式与护城河分析框架（Phase 3 第 1、2 维）

## 第一节：商业模式分析

段永平："商业模式是投资中最重要的事。"回答四个问题，每个都要有明确答案：

1. **怎么赚钱**：收入公式拆到最细（量 × 价，或 用户 × ARPU，或 资产 × 回报率）。钱最终从谁的口袋出来？付钱的人得到了什么？**量与价必须挂 `data/business_drivers_<公司>.json` 的实际数字**（Phase 2 已落盘并过勾稽），不允许只写定性描述——说不出量和价各是多少、各自怎么变，等于没拆开这门生意。
2. **单位经济**：卖一单/服务一个用户，赚多少钱？规模扩大时单位经济变好（规模经济）还是变差（规模不经济）？
3. **客户为什么不走**：复购/续费的真实原因——是没得选、换不动、还是真心喜欢？三者的护城河强度完全不同。
4. **可持续性**：这个赚钱方式 10 年后还成立吗？最可能被什么杀死（技术替代/监管/消费习惯迁移/供应链变化）？

### 所有者代入拷问（本节强制输出，紧接四问之后）

**买股票就是买公司**——把上面四问的答案放到"如果这家公司整体归我"的场景里再过一遍。这不是修辞，而是能逼出前四问漏掉的东西：

1. **如果用现在的市值把整家公司买下来（100% 私有化），我愿意吗？** 明确写出：买下后每年能拿到多少可分配现金（用 Owner Earnings，不是净利润），相当于几个点的收益率（Owner Earnings / 市值 = 所有者收益率），多少年回本。这个数字比 PE 更接近所有者的真实体验。
2. **买下之后，我第一件想改的事是什么？** 答案指向这门生意最脆弱或最被浪费的环节（过度扩张、渠道压货、薪酬结构、无效并购）。若"什么都不想改"，说明公司已被优秀经营——这是强正面信号，但必须给出理由。
3. **这门生意有什么是我不看财报也能理解的？** 一句话说清价值创造的物理过程（把砂变成算力、把水变成品牌溢价、把流量变成撮合）。说不清 → 回到 Phase 0 能力圈终止路径。
4. **我最不希望竞争对手做的一件事是什么？** 这是护城河的反向定位——真正的威胁往往不在当前的竞争维度上（柯达怕的不该是更好的胶卷）。该答案直接进 Phase 5 红队的最强空头逻辑。

### 增长引擎归因（挂 Phase 2 量价分解）

这门生意过去 5~10 年的增长，究竟来自**量**（更多客户/更多门店/更多产能）、**价**（提价/结构升级）、还是**新业务**？三者的所有者含义完全不同：靠价增长通常不需追加资本（品牌型，最优）；靠量增长需要持续 capex 与营运资本（重资产型，要看 ROIIC）；靠新业务则历史财务几乎无参考价值。结论必须与 Phase 2 量价分解图的数字一致，并在 Phase 4 作为收入增速假设的直接依据——**估值里的"增速 X%"必须能说清是量还是价**。

输出格式：一段"用大白话讲这门生意"（假设讲给完全外行听），加一张商业模式画布式要点表，加上述所有者代入拷问四答与增长引擎归因一句话。讲不清楚 = 超出能力圈，回到 Phase 0 的终止路径。

## 第二节：护城河分析（Morningstar 五源框架 + 定量验证）

### 输出词表纪律（v2.15 强制，写在最前是因为它决定后面两道闸门的门槛）

**护城河评级只能输出三个值：宽 / 窄 / 无**（对应 `scenarios.json` 的 `moat` = `wide` / `narrow` / `none`）。禁止自造中间档。

原因不是术语洁癖，而是**两道闸门的门槛直接挂在这个词上**：闸门一的安全边际要求（宽 ≥25% / 窄 ≥40% / 无 → 不给买入结论），以及闸门二由它反推的期望 IRR 门槛（r=10%/H=5 时 16.5% / 21.8%）。评级词一含糊，两个门槛就都无从取值。

归档实测（11 案例）：只有 4 例用了标准词（招行宽、中国建筑窄、台积电宽、微博窄、英伟达宽），5 例用了自造词（拼多多"中强"、泡泡玛特"中级"、腾讯"极强"、伊利"强"），2 例（谷歌、平安）报告里根本找不到明确评级。**自造词无法机械映射到门槛，"极强"是宽还是超宽？"中强"是宽还是窄？——这直接决定安全边际要 25% 还是 40%，差 15 个百分点。**

判定口径（与 Morningstar 一致）：

| 评级 | 判据 | 安全边际要求 |
|---|---|---|
| **宽**（wide） | ROIC 持续显著高于 WACC，且有充分理由认为**未来 20 年**仍能维持 | ≥25% |
| **窄**（narrow） | 当前有超额回报，但只能确信维持**约 10 年** | ≥40% |
| **无**（none） | 无可验证的持续超额回报，或护城河正在被侵蚀且无止损机制 | 不给买入结论（无论多便宜，除非烟蒂式清算价值明确） |

介于宽窄之间拿不定主意时**一律降档取窄**——这是安全边际原则在评级环节的应用，不是妥协。`check_scenarios.py` 的 S1 会硬拒绝非法档位值。

### 步骤 1：定性归类（五源）

| 护城河来源 | 判断标志 | 典型案例 |
|-----------|---------|---------|
| 无形资产 | 品牌带来提价权；专利/牌照排他 | 茅台、迪士尼、创新药专利期 |
| 转换成本 | 客户换供应商的代价高（金钱/风险/学习） | 企业软件、银行核心系统、医械耗材 |
| 网络效应 | 用户越多产品越好用，赢家通吃 | 微信、Visa、交易所 |
| 成本优势 | 规模/工艺/资源/区位带来结构性低成本 | 台积电、Costco、低成本矿山 |
| 有效规模 | 市场只容得下少数玩家，新进入者进来大家都亏 | 机场、管道、区域水泥 |

注意：**好产品、大市占率、优秀管理层本身都不是护城河**。护城河必须回答"为什么竞争对手拿着钱也抢不走"。

### 步骤 2：定量验证（硬证据，缺一项降级）

- **ROIC − WACC 利差**：正利差持续 ≥ 10 年 → 宽护城河候选；≥ 5 年 → 窄护城河候选；时正时负 → 无护城河。这是 Morningstar 的核心检验。
- **毛利率波动带**：10 年毛利率带宽窄且高于同行 → 定价权证据。
- **市占率趋势**：5~10 年市占率稳定或提升。份额持续流失的"护城河"是伪命题。
- **定价权三项硬测试**（巴菲特："判断一家企业最重要的单一指标是定价权"。三项都要有数据，缺数据标明缺失，不许用"品牌力强"之类形容词代替）：
  1. 提价记录：过去 10 年公司实际提价几次、每次幅度（对比 CPI 与行业均价）；
  2. 销量反应：每次提价后销量/市占率是否受损（提价不掉量 = 真定价权）；
  3. 成本转嫁：原材料/人力成本大涨年份，毛利率是守住了（转嫁给下游）还是被压缩（自己硬扛）。
- **进攻者尸检**：过去 10 年谁试图进攻过这个位置？带着多少钱？结局如何？（有资本进攻失败的历史是最强证据；从没人进攻可能只是市场太小）

### 步骤 3：趋势判断（比"有没有"更重要）

护城河在变宽还是变窄？证据：ROIC 利差的方向、市占率二阶导、单位成本差距变化、技术范式是否迁移（柯达的品牌护城河死于数码，不是死于竞争对手胶卷做得更好）。

## 第三节：产业链议价权（五力的纵向两力，直接约束利润率假设）

护城河五源回答"同行为什么抢不走"，本节回答"**上下游为什么分不走**"——利润率的持续性同时受这两个方向挤压，估值里的利润率假设必须同时过这两关。三组证据，全部可从现有底稿与年报附注取数，禁止用"关系稳定"之类形容词代替：

1. **集中度对照**（年报附注披露）：前五大客户占收入比 vs 前五大供应商占采购比。一边高度分散、一边高度集中 → 集中的一方是强势方。危险组合：大客户集中（>30%）且客户自己在做垂直整合（如云厂商自研芯片之于英伟达）。
2. **占款能力趋势**（底稿现成数据）：(应付+预收/合同负债 − 应收 − 存货) / 收入 的 10 年趋势。持续为正且走阔 = 两头占款，产业链话语权强（茅台、Costco 模式）；持续为负且走阔 = 被两头占款，赚的是辛苦钱且在恶化。这是议价权最难粉饰的定量指标。
3. **成本冲击传导记录**（与定价权测试第 3 项联动）：上游涨价年份，公司毛利率与下游客户毛利率谁被压缩？连续两轮冲击都是自己扛 → 对下游无议价权，利润率假设必须按"周期均值偏下"取，禁止按近年高点外推。

输出：上游议价权 强/中/弱 + 下游议价权 强/中/弱 + 一句话依据（挂数据）+ 对估值利润率假设的明确约束（如"下游议价权弱 → 基准情景毛利率取 10 年中位数而非近 3 年均值"）。该约束进入 Phase 4 假设一致性对账的核对清单。

### 输出

护城河评级：宽 / 窄 / 无 + 趋势：变宽 / 稳定 / 变窄 + 一句话核心依据 + 最大侵蚀风险。
