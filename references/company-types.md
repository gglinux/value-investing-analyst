# 公司类型卡：估值语言轴（Phase 2.5 判型，Phase 4 路由）

## 定位：双轴判型

| 轴 | 文件 | 回答的问题 | 使用时机 |
|---|---|---|---|
| 商业模式轴（十一类） | [metric-playbook.md](metric-playbook.md) | 算什么指标、量价口径是什么 | Phase 0 / Phase 2 |
| 估值语言轴（本文件六类） | 本文件 | 现金流用哪套数学：正常化、估值通道、悲观情景、告警语境 | Phase 2.5 判型，Phase 4 路由 |

两轴**正交**：同一商业模式可有不同的现金流生成机制（同为品牌消费品，稳定增长与周期传导的处理完全不同）。判型结果并置披露，互不替代。

## 判型路由三规则

1. **主型唯一（路由职能）**：估值通道与正常化规则只按主型走——一次估值只能按一套数学做正常化。主型唯一不是为了两次分析得出同一结论（结论分歧是判断差异，本身是有价值的信息），而是给分歧一个坐标系：结论不同时，分歧能定位到判型、假设还是权重，battle 才有的放矢；判据全部挂数值字段，保证判型层本身不掺计算噪声，分歧可归因。
2. **标签多元（语境职能）**：告警语境与豁免按**全部适用标签**生效，宁多披露不漏豁免。
3. **边界出带（可见性职能）**：判型落在两卡边界时**不硬猜**——双通道并列输出敏感性带，把判型差异变成可见的结论差异，而不是隐藏的一次掷骰子。

## 主型判定：优先级表

按**误判代价**排序（先排不可逆的），自上而下首个全中判据的型即主型；两型判据同时全中 → 边界态，按规则 3 出带。全部判据挂 `metrics_*.json` 已有字段，禁止凭叙事判型。

| 序 | 型 | 判据（metrics 字段） | 误判代价 |
|---|---|---|---|
| 1 | 转困境 | `normalization.margin_trend = 结构性恶化`（置信=高）；或 `summary.roic_avg_5y` 持续低于资本成本且有息负债/EBITDA 偏高 | 误当稳定增长 → 均值回复正常化 → 系统性高估，不可逆 |
| 2 | 周期 / 传导子型 | `normalization.cyclicality ∈ {周期高位, 周期低位}`，或 `margin_trend = 周期波动`（crossings≥3）；传导子型见卡三 | 基期外推峰值利润 → 高估 |
| 3 | 隐蔽资产 / 控股子型 | 长期股权投资+投资性资产占总资产比重大，或投资收益占利润比重大、并表经营收入占比低（判据见卡四） | 并表污染 → OE 通道假信号 |
| 4 | 快速增长 / 再投入子型 | `summary.cagr_total.revenue` 显著高于市场中枢且增长带质量（见卡二）；再投入子型加 OE 转化判据 | 当期 OE 无解 → 假阴性 |
| 5 | 稳定增长（**默认档**） | `normalization.cyclicality = 中性区间` 且 `margin_trend` 非恶化 | 误判代价渐进，垫底 |
| 6 | 缓慢增长 | 增速低于市场中枢 + 高股息 + 类债特征（见卡五） | 与稳定增长互为边界，代价渐进 |

**判型输出**（写入报告首屏决策卡 + `data/metrics_*.json` 同级的判型小结）：

```json
{
  "valuation_type": {
    "primary": "稳定增长",
    "labels": ["稳定增长", "周期传导"],
    "evidence": {"每型命中的判据与字段值": "..."},
    "boundary_band": false
  }
}
```

判型依据必须逐条列出命中的字段值——判型是**可审计**的，报告读者应能复算。

## 卡一：稳定增长（默认档，OE 通道的正式适用域）

| 要素 | 规则 |
|---|---|
| 判据 | 默认档：cyclicality=中性区间、margin_trend 非恶化、增速在市场中枢附近 |
| 正常化 | 均值/中位利润率锚 + 形状检验（`normalization` 全套），无周期折算 |
| 估值通道 | Owner Earnings 三情景 DCF（主通道）+ 反向 DCF |
| 悲观情景 | 增长降档 + 估值倍数压缩双杀，走独立方法白名单 |
| 高发陷阱 | ① 分红维持的高 ROE 误当内生增长能力（分红率>100% 时留存被消耗、ROE 靠分母做小）；② 传导子型藏在"稳定"里——`position_distortion_hint` 命中时必须归因最新净利率高位的驱动因子，禁止直接按统计均值外推 |

## 卡二：快速增长（含再投入子型）

| 要素 | 规则 |
|---|---|
| 判据 | 增速显著高于市场中枢 + 增长带质量（量价分解健康、无靠单一客户/补贴）；**再投入子型**：另加 `oe_to_ni_conversion` 低 或 capex/收入、获客投入占比高——价值在单位经济与规模效应，不在当期 OE |
| 正常化 | 禁止向历史均值回归（高增长期均值无意义）；基期取最近稳定年度，增速假设必须过基率检验（SKILL 30 秒纪律卡第 5 条） |
| 估值通道 | 标准 OE 三情景前提是 OE 序列有意义；**再投入子型当期 OE 极小时走成长通道**（REQ-P1-01 已接线）：`reverse_dcf.py growth` 以成熟期稳态利润 × 到达概率折回，第一道门是单元经济（规模化边际贡献率 ≤0 或 LTV/CAC <1 → `GROWTH_UNIT_ECONOMICS_UNPROVEN`，通道拒绝服务、改走标准管道）。三段式推导与档位语义（上限小仓位试探）见 [growth-framework.md](growth-framework.md) 第三半节；基准/乐观情景 method 登记 `growth_terminal_backcast` |
| 悲观情景 | 单位经济破坏（获客成本/复购/定价权恶化），不是"增速降 20%"的旋钮式下调 |
| 高发陷阱 | ① 把再投入当低质量（当期 OE 低 ≠ 不赚钱）；② 增长外推当默认（基率检验不过的增速假设一律降档）；③ 零分红公司吃股息类告警（语境豁免按标签生效） |

## 卡三：周期（含传导子型）

| 要素 | 规则 |
|---|---|
| 判据 | cyclicality=周期高位/低位，或 margin_trend=周期波动（crossings≥3）。**传导子型**：cyclicality=中性区间 但主营成本/需求挂钩大宗价格或强周期下游（典型：成本端斜坡回归），配合 `position_distortion_hint` 命中佐证 |
| 正常化 | 中周期利润率均值与中位数双口径交叉验证；大宗商品类用**中周期价格 × 销量**（valuation-guide 已有路径），不用利润率均值 |
| 估值通道 | 方法树强周期行（正常化盈利 × 中枢倍数）；反向 DCF 用中周期基期；**当前周期位置必须独立披露**（顶/底/中段） |
| 悲观情景 | 完整周期底部盈利 × 底部倍数——收入端断崖回归（资源型）与成本端斜坡回归（传导型）的回归速度假设不同，传导子型给更长的回归斜坡 |
| 高发陷阱 | ① 周期高点当结构性改善（margin_trend 的 crossings 检验就是为此）；② 周期底当困境（判别：周期底=盈利能力完好、均值可回复；困境=盈利能力受损或资产负债表问题）；③ 周期波长按所在市场校准——A 股政策周期常短于经典库存周期，不照搬美股波长假设 |

## 卡四：隐蔽资产（含控股子型）

| 要素 | 规则 |
|---|---|
| 判据 | 长期股权投资 + 投资性资产 / 总资产比重大，或投资收益 / 利润总额比重大且并表经营收入占比低。**控股子型**：价值主体在被持股企业而非自身经营（财团、交叉持股、多元集团） |
| 正常化 | 母公司经营性科目与持股收益**分开处理**——并表利润对母公司股东意义有限，看"从被投企业实际收到的分红 + 可处置头寸"。底稿 annual 行登记 `investment_income`（投资收益+公允价值变动，重估推高与减值压低同字段）与 `dividend_income`（从被投企业收到的分红），`compute_metrics.py` 自动产出 `sotp_screen` 块（经营性 OE / look-through 收益分列）并触发 `M_OWNER_YIELD_CONSOLIDATION_DISTORTION`（占净利润比重主导：最新年 ≥50% 或近 3 年 ≥2 年 ≥30%，双向判） |
| 估值通道 | SOTP（分部估值加总，valuation-guide 方法树）。**已落码（REQ-P1-02）**：`python3 scripts/reverse_dcf.py sotp`——结构化持仓表（标的/持股比例/估值方法/变现折价率/流动性/[E:] 六要素，`--holdings-file`）+ 母公司净债（口径显式声明，合并口径触发 `SOTP_NET_DEBT_CONSOLIDATION_BASIS`）+ 经营业务价值（经营+投资双轮形态填，纯控股=0）= equity NAV，× (1−控股折价)；控股折价挂行业基率带（`--holding-profile`，低于下界触发 `SOTP_DISCOUNT_BELOW_BASE_RATE`）；反解现价隐含控股折价（分歧 ≥10pct 触发 `SOTP_IMPLIED_DISCOUNT_GAP`）。持仓占 equity NAV ≥50% 即非经营资产主导（`SOTP_HOLDINGS_DOMINATED`）——OE 通道结论一律不进档位裁决，通道档位上限小仓位试探 |
| 悲观情景 | 分部各自悲观情景 + 折价扩大；不用 DCF 下调 |
| 高发陷阱 | ① 并表污染下的 OE/PE 读数（对控股型输出假低估或假高估——凡是控股子型，OE 通道结论一律不进档位裁决）；② 把折价当安全边际（折价可以永不收敛，没有催化剂的折价不是便宜）；③ 分部数据不可得时按 Phase 0 规则终止，不降级估算 |

## 卡五：缓慢增长（占位——判据待案例锚）

低增速 + 高股息 + 类债特征。正常化预期走股息锚与债券替代比较（股息率 vs 无风险利率 + 信用利差），估值通道以股息贴现 / 回本年数为主。**判据阈值待回测样本后定**，当前判型按优先级表自然落空即落此卡以下，不单独主张。

## 卡六：转困境（占位——判据待案例锚）

结构性恶化 + 债务压力形态。正常化禁用均值回复（向上正常化=假设不会发生的事）；估值走重整价值/清算下限与期权式情景；悲观情景是永久性资本损失而非盈利下降。**判据阈值待回测样本后定。**

## 与林奇六类的差异

骨架保留（分类维度"现金流生成机制 × 增速档"与时代和市场无关，让不同分析者说同一种估值语言），参数重写：增速判据不写绝对数（林奇的 2-4%/10-12%/20-25% 是 1989 年高通胀美股标尺），一律"相对市场中枢 + 质量条件"，三市场中枢由基率检验兜底；三处现代重写——再投入子型、控股升级（SOTP+治理折价）、周期波长按市场校准。
