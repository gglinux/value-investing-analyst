# value-investing-analyst

对单一公司做机构级价值投资深度分析，最终输出一份可通过投委会评审的中文单文件 HTML 报告。

流水线：排雷过滤 → 数据采集（双源核对 + 入口校验）→ 定量画像（统一口径指标）→ 五维定性（商业模式/护城河/增长/管理层/财务质量）→ 估值与安全边际（基期正常化 + 三情景 DCF + 反向 DCF + 期望回报率）→ 关键判断收敛（关键变量/变异认知/机会成本）→ 投委会评审（巴菲特/段永平/李录评分 + 芒格式红队）→ 四档结论（核心买入/观察等价格/太难放弃/排除）+ 证伪条件 + 跟踪清单 + 决策日志。

## 核心设计

- **数据五环校验**：EDGAR/官方源 → `validate_data.py` 入口校验（勾稽/单位突变/双源核对）→ 数据底稿（唯一事实源）→ `compute_metrics.py` 统一口径计算 → `verify_report.py` 报告数字溯源校验。
- **基期正常化关卡**：周期高位公司（最新净利率 > 全期均值 1.25 倍）禁止用当期 Owner Earnings 作 DCF 基期，自动改用正常化基期。这是本 skill 最具价值的纪律——峰值利润外推是周期股估值最经典、最自信的翻车方式。
- **期望回报率引擎**：安全边际只回答"贵不贵"，期望年化 IRR/亏损概率才回答"划不划算"。四档结论由双闸门唯一决定（安全边际达标 且 期望年化跑赢机会成本），三人评分只呈现分歧不改变档位——好公司 ≠ 好价格。

## 使用

把本目录作为智能体 skill 加载，直接对它说"分析一下 XX 公司（股票代码）"即可。流程细节见 `SKILL.md`，方法框架见 `references/`。

## 目录

```
SKILL.md                 主流程（八阶段流水线 + 核心纪律 + 数据源协议）
assets/                  HTML 报告模板
references/              方法框架（排雷/护城河/增长/管理层/估值/投委会/报告规范）
scripts/                 数据校验与计算引擎
  validate_data.py       入口校验（三表勾稽/单位突变/双源核对）
  compute_metrics.py     统一口径指标（ROIC/ROIIC/Owner Earnings/正常化基期）
  reverse_dcf.py         反向 DCF + 三情景正向 DCF + 期望回报率
  verify_report.py       报告数字与底稿比对（发布前强制）
examples/nvidia/         黄金样例（英伟达完整分析 + 基期正常化实证，2026-08）
```

## 黄金样例

`examples/nvidia/` 是一次真实全流程分析，特意保留了初版估值错误（峰值基期）与修订结果（正常化基期）的对照——亏损概率 30% → 80%，是"基期正常化"关卡价值的实证。

## 边界

不构成投资建议，只输出企业价值判断与安全边际结论；报告含免责声明。
