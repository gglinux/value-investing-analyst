## 存档说明

- 每案例目录结构：`data/`（底稿 JSON，可直接被 verify_report/compute_metrics 重放）、`workpapers/`（三大师+红队+定性底稿）、`decision-log.md/.json`、最终 HTML 报告。
- 为控制体积，**未存档**：年报原文 PDF/10-K（`data/filings/`，manifest 登记了来源可重新下载）、接口原始返回（`raw_finance_*.json`）。校验脚本重放时证据指针核验会降级为警告，属预期。
- 内容已脱敏：不含个人持仓、成本价位与内部平台标识；决策日志中的"用户初判"仅保留分析方法所需的判断内容。
