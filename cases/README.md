# 案例库（Case Library）

本目录是 skill 的实证案例存档：每个案例是一次完整的真实分析（数据底稿、工作底稿、三大师评估、红队质询、决策日志、最终报告），既供回溯复盘，也是 skill 迭代的测试集——每轮案例复盘暴露的问题都会固化为引擎修复（见根 README 的版本记录）。

## ⚠️ v2.9 期望回报口径勘误（影响下表 4 个案例的闸门二结论）

下表"双闸门"列的 IRR 均为**旧口径**（`IRR=(V0/P)^(1/H)−1+股息率`），该式隐含"内在价值 5 年原地不动、期间赚的现金凭空消失"，对留存再投资的公司系统性低估 3~10 个百分点。按修正口径 `IRR=(1+r)×(V0/P)^(1/H)−1`（r=10%，股息已隐含、不再叠加）重算：

| 案例 | 旧 IRR | 修正 IRR | 闸门二 |
|---|---|---|---|
| cmb 招商银行 | 7.63% | **12.77%** | ✗ → ✓ 翻转 |
| pdd 拼多多 | 4.53% | **14.98%** | ✗ → ✓ 翻转 |
| tencent 腾讯控股 | 3.75% | **12.84%** | ✗ → ✓ 翻转 |
| pingan_china 中国平安 | 6.84% | **12.24%** | ✗ → ✓ 翻转 |
| yili 伊利股份 | 1.69% | 6.21% | ✗ 仍不过 |
| tsm 台积电 | −3.82% | 4.91% | ✗ 仍不过 |
| goog 谷歌 | −5.14% | 4.07% | ✗ 仍不过 |
| nvidia 英伟达 | −10.64% | −1.71% | ✗ 仍不过 |
| popmart 泡泡玛特 | −8.39% | −1.13% | ✗ 仍不过 |
| weibo 微博 | 29.07% | 32.40% | ✓ 仍通过 |

**但"翻转为通过"不等于"应该买入"。** 修正同时暴露：旧默认门槛 9% < 折现率 10%，闸门二本就形同虚设（买在内在价值上 IRR 恒等于 r，自动过闸）。新纪律要求门槛取 `max(指数年化, r+3pct)`=13%，且核心买入档追加下行约束（悲观情景 IRR ≥ 0、亏损概率 ≤ 30%）。**按新口径 + 新门槛 + 下行约束 + 闸门一完整重算，10 个案例中仅微博 1 个双闸门全过**（初版勘误曾把拼多多判为“核心买入”，系不完整判定：只验了闸门二三项、漏了闸门一——拼多多安全边际 21% < 25% 未达标，其决策日志原文即“差 4 个点”，已于 2026-09-01 修正）：

| 案例 | 修正 IRR | 过 13% 门槛 | 悲观情景 IRR | 亏损概率 | 新纪律下档位 |
|---|---|---|---|---|---|
| pdd 拼多多 | 14.98% | ✓ | +12.90% | 0% | 观察·等价格（闸门二三项全过，闸门一 21%<25% ✗，等待价 80.41 美元） |
| weibo 微博 | 32.40% | ✓ | +28.34% | 0% | **核心买入**（三项全过） |
| pdd 之外的 4 个翻转案例 | 12.2~12.8% | ✗ | 3.7~9.3% | 0% | 仍为观察等价格（IRR 差 0.2~0.8pct） |

招行/腾讯/平安三个"翻转"案例修正后 IRR 落在 12.2~12.8%，距 13% 门槛仅差 0.2~0.8 个百分点——**这个"差一点"恰好说明门槛校准的重要性**：门槛设 9% 则三者全过、设 13% 则全不过，闸门二的判别力几乎全部来自门槛取值而非公司质量差异。这提示单靠 IRR 门槛做二次筛选本就脆弱，下行指标（悲观 IRR 分别为 6.79%/9.33%/3.69%，平安明显最弱）才是更有分辨力的信息。

**2026-09-01 更新：引擎级重跑已完成**（新口径 + 13% 门槛 + 下行约束，现价取当日行情，三情景价值沿用存档假设未复核，结果存于各案例 `data/expected_return_v29_rerun.json` 与决策日志当日条目）：招行 40.53 元（期望 IRR 12.15%）、平安 56.81 元（11.85%）双闸门仍不过；腾讯 442.4 HKD 闸门二首次全过（13.48%、悲观 +9.96%，超额仅 0.5pct 且主要靠乐观情景抬升）而闸门一仅 8.4%；拼多多 84.00 美元闸门二全过（15.17%、悲观 +13.08%）而闸门一 21.6% 差 3.4pct。四个案例档位均维持**观察·等价格**，双闸门全过等待价（均由闸门一约束）：招行 35.25 元 / 腾讯 362.1 HKD / 平安 50.01 元 / 拼多多 80.41 美元。按 skill 纪律，**完整流程重跑（含估值假设复核）仍是正式改档的前置条件**。存档的 `expected_return.json` 与 HTML 报告保持当时口径原样（不追溯改写，保留决策历史的真实性）。
