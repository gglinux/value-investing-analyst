## 四、根因分析（命中案：为什么对，哪些部分经不起反事实）

**排除项**：
- ❌ 数据错：全链路校验绿（validate_data 0 错误 / check_scenarios 0 警告 / 保险管线 0 警报且重跑无漂移 / verify_report 128/128）；市值数量级错误（10,255 亿误存 102,552 亿）在 verdict 提交前由快照三角校验捕获并修正留痕。
- ❌ 逻辑错：保险管线严格按方法树运行（EV 两阶段贴现 + Gordon 禁用 + P/EV 双口径裁决）；Gate2③ 边缘性（+1.97%）附独立谷底倍数对照（招行案 −0.04% 的镜像），未 p-hack。
- ❌ 执行污染：先验（观察等价格/闸门不预判）冻结于分析前（commit 2c97433），与输出一致，也与官方集相容。

**命中机制分析（按重要性排序）**：

1. **【档位命中的真实来源是 Gate1 绝对门槛 + 官方集的宽容】**MoS 4.9% vs 40% 的差距（8 倍）大到任何参数微调都无法翻越——与招行案"差 0.02 元"的边缘失败不同，本案的保守输出是**深度**而非**边际**。但必须诚实登记：官方集 {3,2} 中小仓位试探(3) 也是官方可接受档——若系统的 Gate2① 差距更小（11.63% vs 22.05% 的 1.6pct 量级差距在 hurdle_derivation 里已登记），档位可能升到 3 仍命中。**命中不依赖档位的精确落点，依赖官方把"不确定"本身作为合法答案**——这是回放方法学对模糊性的正确处理，而非引擎判别力的证明。
2. **【触发价深度是本案命中的实质内容】**35.40 = IV×0.6（窄护城河 40% 折扣），比 52 周低点再下 34.8%——这个"看似过分苛刻"的定价在 4 年后被证明几乎恰好是底部区域（35.90）。与招行案同参数结构（IV×0.6）输出相反的历史命运：招行的触发价 12.39 永远等不到，平安的 35.40 差 1.4% 等到——**差异不在触发公式，在标的事后的估值路径**（招行 EPS+63% 复利上行，平安 NBV 断崖+利差收窄估值坍缩）。同一公式在两个标的上"正确/无效"各一次，说明触发价公式本身没有判别力，判别力来自 Gate1/Gate2 对基本面质量的过滤。
3. **【盲区无实质影响——但要区分"本案无影响"与"盲区无害"】**两处保险管线盲区（利差转负、NBV 减速）事后均兑现，但即便信息完备，2018-12-31 看到这两处负信号只会**加固**观察等价格（更保守），不会翻档。盲区的真实风险敞口在反向案例：若某保险标的的半年报利差恶化是暂时的，年报口径的不可见反而会避免误杀——盲区是双向风险，本案恰好落在无害方向。登记为管线改进候选（Phase 5 工程项），不改档位逻辑。
4. **【数据卫生三勘误（post-hoc 环节的诚实记录）】**①训练记忆中的财年 DPS 序列错位一年（2.05/2.20/… 实为 FY2019-2023，FY2018 应为 1.72）——由东财 RPT_SHAREBONUS_DET 与独立除息日事件交叉裁决；②30 周年特别股息 0.20 无独立除息记录，登记歧义（对窗口回报零影响）；③fqt=2 月线 2018-12 异常（见口径声明）。三条均不影响 verdict（回放时点输入全部来自 2018-12-31 前官方文件），但前一条再次验证 OBS 系列的教训：**训练记忆不得作为数据源，机器 API 为裁决方**。

## 五、与 meta.json 先验预期的自检
