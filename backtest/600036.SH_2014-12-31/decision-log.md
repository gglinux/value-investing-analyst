### Phase 3：五维定性
- 护城河：**窄（侵蚀中）**——负债成本优势真实，但存款保险征求意见稿（2014-11-30）+利率市场化在拆除管制折价的立法基础；资产端无定价权。

### Phase 4：估值（银行两阶段 PB-ROE 首次实盘）
- **估值树**：分红折现 + 终期 BVPS×终期 PB；单阶段 Gordon 禁用（招行实证误差 +141%）。
- **人工周期调整**：管线 sustainable_roe = 21.66%（后视镜均值）被否——信用成本警报触发后，采用 19%→13.5% 十年衰减路径（payout 30%）。这是管线给不出、必须人做的判断（diff.md 候选）。
- 三情景（S1–S9 全过 0 警告）：悲观 **10.05**（实测 pb_trough 0.84 × BPS 11.97，S2d 证据：不复权+最低点）/ 基准 **20.65**（PV 分红 5.45 + 终值折现 15.20，终值占比 74%）/ 乐观 **32.97**（ROE 21→19、终期 PB 1.6）。离散度 ≤0.85。
- 反向定价：现价隐含永续 ROE 11.46%——12 月疯牛 = 市场叙事从"ROE→COE 完全回归"升级为"收敛但存活"。
- **闸门一**：MoS 19.7% < 40%（窄）→ **FAIL**。触发价 12.39 = 20.65×0.6。
- **闸门二**：①期望 IRR 14.41% < 22.39% **FAIL** ②不收敛下限 8.24% ≥ 6% PASS ③悲观年化 −0.04% < 0 **FAIL**（差 0.02 元：悲观 10.05 vs 通过线 10.07；曾核算 0.845 倍 trough 即可过线，**保留 0.84 实测值，拒绝 p-hack**）→ **FAIL**。
- 触发价可达性：12.39 处 52 周带 [9.41, 16.62] 内 41.3% 分位，需自现价 16.59 下跌 25.3% → **TRIGGER_REACHABLE**。

### Phase 4.5：关键变量收敛
1. **信用成本路径**（最重要）：不良生成率是否冲向 2%——季度不良率+关注类+逾期率三线跟踪；若冲 2%+，触发价重估前移，不等待 12.39。
2. **负债优势衰减速度**：存款利率放开节奏与活期占比变化——年报/半年报披露。
3. **拨备/资本约束**：拨备覆盖率下行的资本反噬（约束分红与扩张）——定期报告直接披露。

- 巴菲特：观察等价格（窄护城河侵蚀中、信用成本超调警告）；段永平：观察等价格（不猜坏账深度，触发价兜底）；李录：观察等价格（隐含 ROE 11.46% 说明市场定价不荒谬，便宜的是赔率不是价值）。
