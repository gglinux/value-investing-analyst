- **污染源**：PROMPT 第七节答案文本 + 康美爆雷系著名公共事件（2018-12 立案、2019-04 自爆 299.44 亿），执行者不可能真盲测。
- **污染对本案的实际影响 = 零（结构上可辩护）**：三条一票否决/红旗证据链（存贷双高 50.15%/41.93%、利率倒挂 0.84% vs 4.86%、七年 OCF/净利 51.2%）全部来自公司**自己披露**的三季报/年报，均为截断日前官方文件；Phase 0 机械条款（清单第 3/4 条）在官方文件上即可触发，不依赖任何举报、外部质疑或事后信息。污染最多影响「先验预期的书写顺序」（meta.json 已披露），不影响算术。
- **反向检验**：即便假装不知道答案，面对「账面 327 亿现金同时付出 4.86% 举债 274 亿」这一事实，任何执行者都无法在不违反清单第 4 条的情况下给「通过」——该条款自带康美案例名，本案是条款原型的实盘还原。

## 五、机制观察（转 Step 5 的observations 登记）

1. **排雷不需要侦探能力，需要算术纪律**：本案全部证据来自公司自己披露的报表。Phase 0 的价值不在「发现别人发现不了的线索」，而在「不放过任何人都能看到的矛盾」——0.84% vs 4.86% 的倒挂挂在那里 4 年（2013 年报起存贷双高形态已可见）。
2. **利率倒挂是存贷双高的加强验证器**：单看存贷双高可能有「行业特性/资金归集」等辩解空间，叠加利率倒挂后辩解空间归零——两个信号相乘的证伪力远大于相加。
3. **未判定项的教训**：存货/应收两项红旗因数据未采集而「未判定」，事后看存货正是最大隐藏科目（少计 195 亿）。不影响本案结论（否决线已过），但暴露 Phase 0 底稿采集清单的缺口 → OBS-2017-12-01。
4. **防漏放成功**：meta.must_not_trigger 为空，本案无防误伤任务；系统在「该排雷时排雷」上的行为与官方完全一致，验证了 Phase 0 的触发灵敏度。
